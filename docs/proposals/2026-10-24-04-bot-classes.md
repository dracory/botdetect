# Proposal: bot classification

Status: proposed
Date: 2026-10-24
Spikes: `docs/spikes/go-ua-parser/README.md`,
`docs/spikes/aibouncer/README.md`

## Problem

`IsBot` returns a flat bool, but consumers need to *differentiate*: block
scrapers and scanners, allow search engines (SEO), maybe allow or observe
AI crawlers, never block user-initiated fetchers like `ChatGPT-User`
(a human clicking a link in ChatGPT).

## Proposal

Introduce a class taxonomy (adopted from go-ua-parser's `Bot.Class`,
extended with `ClassScanner` and AI user-fetcher differentiation from
aibouncer's `Purpose`):

```go
type BotClass string

const (
    ClassSearch  BotClass = "search"   // Googlebot, Bingbot, DuckDuckBot, ...
    ClassSocial  BotClass = "social"   // Twitterbot, FacebookExternalHit, LinkedInBot, ...
    ClassAI      BotClass = "ai"       // GPTBot, ClaudeBot, Google-Extended, Bytespider, ...
    ClassAIUser  BotClass = "ai-user"  // ChatGPT-User, Perplexity-User, Claude-Web (human-initiated fetch)
    ClassSEOTool BotClass = "seo-tool" // AhrefsBot, SemrushBot, PetalBot, ...
    ClassMonitor BotClass = "monitor"  // Pingdom, Datadog, Site24x7, UptimeRobot, ...
    ClassScraper BotClass = "scraper"  // curl, python-requests, scrapy, headless, ...
    ClassScanner BotClass = "scanner"  // sqlmap, nikto, nmap, masscan, zgrab, cve-, ...
    ClassOther   BotClass = "other"    // generic/unclassified bots
)

type Detection struct {
    Bot   bool     // true if identified as a bot
    Name  string   // normalized bot identifier (e.g. "googlebot", "gptbot", "chatgpt-user", "sqlmap")
    Class BotClass // empty string when Bot is false
}

func Detect(userAgent string) Detection
func DetectRequest(r *http.Request) Detection
```

### Classification & naming rules

1. **Specific patterns before fleet-level `uasurfer` constants for AI bots**:
   `uasurfer` v0.3.1 collapses multiple agents from the same vendor into a
   single `BrowserName` — e.g. `GPTBot` (training crawler), `OAI-SearchBot`
   (search), and `ChatGPT-User` (human clicking a link) all become
   `BrowserOpenAIBot` (and similarly `ClaudeBot` + `Claude-Web` become
   `BrowserAnthropicBot`). To preserve both the specific `Name` (`"gptbot"`
   vs `"chatgpt-user"`) and the distinction between `ClassAI` and
   `ClassAIUser`, check our specific bot classification table before falling
   back to `uasurfer`'s fleet constant.
2. **Lookup table, not a separate parser**:
   - Our specific patterns and `uasurfer`'s named bot constants map directly
     to `(Name, BotClass)` in a static table.
   - Generic `uasurfer.BrowserBot` hits, broad word-boundary hits (`"bot"`,
     `"crawler"`, `"spider"`), and unclassified vendored `crawlers.json`
     regex hits map to `ClassOther`, with `Name` populated from the matched
     token (via `crawlersRegex.FindString` or `"bot"`).
3. **`IsBot` and `IsBotRequest` become thin wrappers**:
   - `IsBot(ua)` returns `Detect(ua).Bot`.
   - `IsBotRequest(r)` returns `DetectRequest(r).Bot`.

## Impact

- Middleware policy can allow `ClassSearch` and `ClassAIUser`, block
  `ClassScanner` and `ClassScraper`, and allow/block/observe `ClassAI` and
  `ClassSEOTool` — the core use case that motivated `botdetect`.
- Distinguishing `ClassAIUser` (`ChatGPT-User`, `Perplexity-User`) from
  `ClassAI` (`GPTBot`, `ClaudeBot`) prevents sites from accidentally blocking
  human-initiated link visits from AI assistants.
- Separating `ClassScanner` (`sqlmap`, `nikto`, `nmap`, `zgrab`, `cve-`) from
  `ClassScraper` (`curl`, `python-requests`) lets consumers hard-ban exploit
  scanners while merely rate-limiting or logging generic HTTP clients.
- `statsstore` / `statsadmin` can break down bot traffic by `BotClass` and
  `Name`.
